# Library Management System

## Опис проєкту

Library Management System — це консольна програма, реалізована мовою C++, 
що моделює роботу бібліотеки.

Система дозволяє керувати книгами, користувачами та процесом видачі книг.

Проєкт побудований з використанням принципів об'єктно-орієнтованого програмування
та має модульну структуру (app + lib).

---

## Мета програми

- Зберігання інформації про книги
- Реєстрація користувачів
- Видача та повернення книг
- Облік активних позик

---

## Основні класи

###  Book
Представляє книгу в бібліотеці.
Містить інформацію:
- назва
- автор
- рік видання
- статус (доступна / видана)

---

###  User
Представляє користувача бібліотеки.
Містить:
- ім'я
- ID
- список активних позик

---

###  Loan
Представляє факт видачі книги.
Містить:
- книгу
- користувача
- дату видачі
- дату повернення

---

###  Library
Центральний клас системи.
Відповідає за:
- зберігання книг
- зберігання користувачів
- створення позик
- повернення книг
- пошук книг

---

##  Принцип роботи

1. Користувач реєструється.
2. Бібліотека зберігає інформацію про книги.
3. Користувач може взяти книгу.
4. Створюється об’єкт Loan.
5. При поверненні книга стає доступною.
