    ##Звіт до Лабораторної роботи №3##
    
##Тема: Робота з класами та об’єктами. Реалізація бібліотечної системи
Дисципліна: Об’єктно-орієнтоване програмування
Студент: Гамадрила Данило##
Мета роботи:

Ознайомитися з принципами об’єктно-орієнтованого програмування, зокрема:

створенням ієрархії класів;

використанням віртуальних методів і поліморфізму;

роботою з колекціями;

організацією взаємодії між класами в межах проєкту.

Завдання:
Розробити програму «Бібліотека», яка реалізує такі можливості:
Клас Book — зберігання інформації про книги (назва, автор, ISBN, доступність).
Клас Reader — моделює читача бібліотеки.
Клас User (батьківський клас) — з основними полями name, id, email.
Клас Library — основна логіка:
завантаження книг і читачів з файлів;
видача й повернення книг;
пошук по назві, автору або ISBN;
список читачів і їх позичених книг.
Використання поліморфізму через віртуальні методи.
Логічна обробка помилок (повернення булевих значень).
Відсутність консольного виводу — вся логіка працює програмно.

Структура проєкту:

Опис виконаних доробок:

У лабораторній роботі №3 було:

    1. Оновлено структуру класів
Додано базовий клас User.
Реалізовано спадкування Reader : public User.
Додано віртуальні методи displayInfo() та notify().

    2. Перенесено функціонал з LAb1 та об’єднано
Усі функції з LAb1 були перенесені й інтегровані в Lab:
Завантаження даних з файлів.
Пошук книг.
Видача та повернення книг.
Робота з вектором ISBN у читачів.

    3. Виправлено помилки та додано перевірки
Перевірка наявності книги.
Перевірка, чи книга вже зайнята.
Неможливо позичити книгу двічі.
Неможливо повернути те, що не позичав.

    4. Усунуто весь консольний вивід
Код працює як модуль ядра бібліотеки, який можна інтегрувати в GUI.

##Висновок:##
У лабораторній роботі реалізовано повноцінну об’єктно-орієнтовану модель бібліотеки з використанням поліморфізму, інкапсуляції та спадкування. Код був оптимізований, очищений від консольного виводу та підготовлений до інтеграції у графічний інтерфейс.
